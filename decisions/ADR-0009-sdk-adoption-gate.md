# ADR-0009 — SDK adoption gate
Status: accepted strategic intent; implementation pending
Owner: ShadowWalkerNC
Date: 2026-10-03

## Requirement and context
Dependencies must solve established requirements with manageable maintenance and lock-in.

## Decision
Classify significant SDK candidates ADOPT, OPTIONAL, REJECT or REVISIT through decision records covering requirements, alternatives, license, price, offline behavior and removal path.

## Alternatives and consequences
No automatic installation. First-party SDKs follow stable contracts. Blueprint interest in a vendor is not an adoption decision or verified pricing/license evidence.

## Evidence and execution gate
Accepted by the owner's canonical Master Blueprint v4.0, sections 28, 32, 124–125. This record documents that supplied decision; it does not certify implementation or authorize gated mutations.
