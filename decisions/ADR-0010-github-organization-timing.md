# ADR-0010 — GitHub organization timing
Status: accepted strategic intent; implementation pending
Owner: ShadowWalkerNC
Date: 2026-10-03

## Requirement and context
Branding changes must not precede stable architecture and ownership boundaries.

## Decision
Keep ShadowWalkerNC ownership during consolidation. Consider mature product organizations only after documented readiness and explicit migration approval.

## Alternatives and consequences
Preserve repository history, consumers and rollback plans. No repository transfer, organization creation or permission change is authorized by this decision.
