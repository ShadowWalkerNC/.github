# Project facts template

Owner: ShadowWalkerNC · Version: 1.0.0 · Applies to: explicitly adopted project scope.
Canonical location: `templates/PROJECT_CACHE.md`.

Record verified stack, commands, ownership, important decisions, known issues,
and evidence dates. Link canonical docs rather than copying facts. Keep secrets,
private reasoning, and machine-specific paths outside public Git. Update durable
facts when they change, not after every task by default.
