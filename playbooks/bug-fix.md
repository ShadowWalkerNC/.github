# Bug fix

Owner: ShadowWalkerNC · Version: 1.0.0 · Applies to: explicitly adopted project scope.
Canonical location: `playbooks/bug-fix.md`.

Reproduce the actual failure, narrow the affected path, inspect state and contracts, identify the root cause, and make the smallest coherent fix. Verify the original failure and a meaningful regression case where warranted. Preserve unrelated behavior and report baseline failures separately.
