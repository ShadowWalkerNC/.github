# sdk standard
Create first-party SDKs after contracts stabilize and consumers justify them. Keep transport/auth/error types explicit and business logic in the domain service. Document compatibility, examples, versioning and removal path; validate consumer contracts. Existing declared packages are not automatically adopted for new functionality.
