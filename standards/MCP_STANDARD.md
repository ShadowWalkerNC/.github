# Mcp Standard

Owner: ShadowWalkerNC · Version: 1.0.0 · Applies to: explicitly adopted project scope.
Canonical location: `standards/MCP_STANDARD.md`.

MCP adapts an authenticated domain API/service; it must not bypass domain validation or access the database through a secret path. Publish versioned tool/input/output contracts, enforce caller/capability permissions and audit durable actions. Test denial, invalid input and side-effect boundaries.
