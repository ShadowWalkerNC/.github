# versioning standard
Version APIs, SDKs, MCP tools, typed events, plugin/extension manifests and project/capability schemas. Preserve backward compatibility where possible. Breaking changes record consumers, migration/deprecation window and contract validation. Publishing releases needs approval; a generated version suggestion does not publish.
