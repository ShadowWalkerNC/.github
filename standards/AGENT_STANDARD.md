# Agent Standard

Owner: ShadowWalkerNC · Version: 1.0.0 · Applies to: explicitly adopted project scope.
Canonical location: `standards/AGENT_STANDARD.md`.

Use minimum relevant context and one capable agent by default. Recommend providers by task fit and documented cost/latency/quality evidence, with user override. Shared task state contains decisions, files, checks, blockers and next step; private reasoning stays private. Multi-agent plans need approval and non-overlapping ownership. Preserve prior agent artifacts.
