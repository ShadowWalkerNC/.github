# Repository standard
Use one primary classification and lifecycle from the portfolio schema. Keep observed provider state separate from designated portfolio state.
Every active repository needs forge.project.json and canonical README, AGENTS, ARCHITECTURE, STATUS, ROADMAP, CHANGELOG and SECURITY documents, or an explicit maturity/location exception with owner and closure phase.
Inspect existing docs and repository-local instructions before rollout. Preserve unrelated edits, agents/, upa/, and useful Muse research.
Do not create empty folders. Do not create one repository per adapter or package.
Record license evidence; an unrecognized or absent license is not permission to select one.
Changing repository names, visibility, archive state, ownership or organization needs specific approval and a recoverable baseline.
